WorkBuddy-OAuth

个人项目 · Personal project

应用名称 / App name: WorkBuddy-OAuth

一个供开发者本人使用的 Gemini API 命令行客户端。它通过 Google OAuth 2.0 在本地完成账号授权，然后以授权账号的身份调用 Gemini API 生成内容。

A command-line client for the Gemini API, used by its developer. It authenticates locally via Google OAuth 2.0 and calls the Gemini API on behalf of the authorizing account.

功能 / Features

  • 本地运行，无服务端，不收集任何用户数据
    Runs locally. No server, no user data collection.
  • OAuth 2.0 授权后调用 Gemini API 完成文本生成
    Calls the Gemini API for text generation after OAuth 2.0 authorization.
  • 授权令牌仅保存在使用者本机
    Access and refresh tokens are stored only on the user's own machine.
