隐私权政策

Privacy Policy

适用应用 / Applies to: gemini-personal
简明版：本应用是开发者本人使用的本地命令行工具，不运营任何服务器， 不收集、不上传、不共享你的任何数据。授权令牌只保存在你自己的电脑上。 Summary: this is a local command-line tool used by its developer. It runs no server and collects, uploads, or shares no data. Tokens stay on your own machine.

1. 我们访问哪些 Google 数据

当你通过 Google 账号授权本应用时，应用会获得以下权限：

  • https://www.googleapis.com/auth/generative-language.retriever —— 以你的身份调用 Gemini API 生成内容
  • https://www.googleapis.com/auth/cloud-platform —— Google Cloud 平台基础访问权限

应用不会读取你的 Gmail、Google 云端硬盘、通讯录、日历或任何其他 Google 服务中的内容。

The app requests only the two scopes above. It does not access Gmail, Google Drive, Contacts, Calendar, or any other Google service data.

2. 数据如何被使用

访问权限仅用于一个目的：把你输入到命令行的文本发送给 Gemini API，并把返回结果 显示给你。请求结果不会被记录到任何远程位置。

The access is used solely to send your command-line input to the Gemini API and display the response. Responses are not recorded anywhere remote.

3. 数据存储与保留

  • OAuth 访问令牌与刷新令牌以明文文件形式保存在运行本应用的电脑上 （文件路径由使用者本机决定），不会发送到任何第三方。
  • 除上述令牌外，应用不保存任何用户数据。删除该令牌文件即等于清除全部本地记录。
  • 本应用没有服务端数据库，因此不存在远程保留的数据。

Tokens are stored as a local file on the machine running the app. No other data is stored, and there is no server-side database.

4. 数据共享

不会。应用不会将任何数据出售、出租或分享给第三方。数据仅在必要时于你的电脑与 Google API 之间直接传输。

No. No data is sold, rented, or shared with third parties. Data is transmitted only directly between your machine and Google's API.

5. 如何撤回授权与删除数据

  • 随时可在 Google 账号的「第三方应用和服​务」页面撤销本应用的访问权限。
  • 删除本机保存的令牌文件即可移除全部本地数据。

Revoke access anytime at Google Account → Third-party apps & services; delete the local token file to remove all local data.

6. Google API 服务用户数据政策

本应用对从 Google API 获得的信息的使用遵守 Google API 服务用户数据政策，包括其中的有限使用（Limited Use）要求。

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

如本政策发生实质性变更，将在本页面更新并修改页脚的「最后更新」日期。

Material changes will be posted on this page with an updated date below.
